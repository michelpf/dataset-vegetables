# Vegetable Image Dataset

This dataset was originally downloaded from [Kaggle](https://www.kaggle.com/datasets/misrakahmed/vegetable-image-dataset).

The goal of this repository is to facilitate the teaching of Python classes with organized data.

In this dataset there are 21000 images from 15 classes, where each class contains a total of 1400 images.

This dataset was adapted for use in Machine Learning classes.
